Backend Event Flow — Order State Machine
[EVENT] order.placed → {order_id, user_id, merchant_id, items[], payment_method}
[TRIGGER] Payment Gateway (Razorpay) → payment.captured event → Kafka topic: payments
[TRIGGER] Inventory Service: reserve_stock(item_ids, quantities) → inventory.reserved
[PUSH] Merchant Notification Service → FCM push + SMS → merchant.notified
[TIMEOUT] If merchant.accept not received in 90s → auto_accept OR reassign to next eligible merchant
[TRIGGER] Rider Assignment Service → geo-query within 3km radius → score(proximity, rating, load) → rider.assigned
[STREAM] Location Service: WebSocket session open → rider GPS → ETA recalculation every 15s
[EVENT] order.picked_up → POD photo captured → delivery.in_progress
[EVENT] order.delivered → OTP verified → settlement.initiated → merchant credited T+2
[FAILURE] Any step timeout → escalation.triggered → ops_team.alert → customer_notified
